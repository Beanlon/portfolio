# Portfolio

A student portfolio built with React, Vite, and Tailwind CSS.

## Project structure

```
src/
  App.jsx          # app entry + root component
  components/      # UI components
  data/            # portfolio content
public/            # images
vite/setup.js      # auto-generates index.html + global styles
```

`index.html` is generated automatically when you run dev or build — you don't need to manage it.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
